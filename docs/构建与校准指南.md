# 本地构建与校准

## 构建

使用 Windows x64、PowerShell 7、.NET SDK 8.0.4xx。首次执行需联网还原固定版本的 NuGet 依赖。仓库不包含 SDK、个人环境清单或远端构建工作流。

```powershell
pwsh -File scripts/build-release.ps1
```

输出在 `artifacts/`，源码路径映射到 `/_/`，不分发 PDB。运行包完整解压后启动 `DeltaCrafter.Fixed.exe`。构建脚本拒绝覆盖已有 artifacts 目录；请先人工归档上一轮输出，或使用干净工作副本。

## 默认资源

`src/DeltaCrafter.Core/Data/items.json` 与 `anchors.json` 是允许发布的内置模板；本地初始化副本、截图、日志和个人计划不进入仓库或 ZIP。

标题 ROI 为归一化坐标 `(0.325, 0.148, 0.30, 0.056)`，按客户区宽高缩放。回归测试验证 1920×1080 和 2560×1440 的像素边界；实际游戏布局、窗口缩放与 OCR 仍需实机确认。

## 验收边界

手电别名、长标题区域、倒计时解析和原有单元测试必须全部通过。新旧版本数据目录隔离，不导入已有任务，不以取消制造作为测试步骤。合成文本不是完整 OCR 引擎或端到端游戏验证的替代品。

## 发布与回退

仅以源码允许清单创建独立提交，使用公开 GitHub noreply 身份。先审查源码、所有提交和解压包，再上传私有暂存仓库；本地验收完成后才公开预发布。ZIP 与 SHA-256 必须配套，上传后重新下载核对。

回退时退出修复版，保留自己的数据备份并恢复上一版本程序文件。若发现隐私遗漏立即停止分发并清理附件/历史；已公开内容可能已经被复制，无法承诺完全撤回。
